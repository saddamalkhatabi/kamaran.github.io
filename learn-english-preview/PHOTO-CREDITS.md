# Photographic scene asset credits

This first web prototype uses contextual **real-life photography** from Pexels, with the original locally drawn `assets/scenes.svg` as an offline/failed-network fallback. These photos are **not** original AI-generated assets; the separate generated concept image is an independent design reference. Production publication should download, optimize, and self-host correctly licensed media, and manually review each scene/photo association.

All URLs correspond to free-license Pexels photo pages reviewed while authoring this revision. Public hotlinks use `images.pexels.com/photos/<id>/pexels-photo-<id>.jpeg?auto=compress&cs=tinysrgb&w=960`.
